# コミット履歴可視化アプリ

Gitのコミット履歴CSVをアップロードすると、テーブル表示と曜日ごとのコミット件数の棒グラフを表示するDashアプリです。

---

## 概要

- CSVをアップロードすると、コミット履歴をテーブルとして表示
- 日付から曜日を算出して、曜日ごとのコミット件数を棒グラフで可視化
- ユーザーが直感的にコミットの分布を確認可能

---

## 機能

- CSVアップロード（.csv形式のみ）
- コミット履歴のテーブル表示
- 曜日ごとのコミット数を棒グラフで表示
- テーブルはページング対応（1ページ10件表示）

---

## 必要環境

- Python 3.12.6 推奨
- 推奨: 仮想環境 (venv / uv) を使用すると依存関係を分離できます（必須ではありません）

---

## 依存ライブラリ

以下をインストールしてください：

```bash
pip install pandas dash dash-uploader
```

---

## 使用方法
1.コミット履歴を調べたいGitリポジトリに移動
cd path/to/repo

2.CSVファイルを作成
echo "date,detail" > log.csv
git log --date=short --pretty=format:"%ad,%s" > log.csv

3.アプリを起動
python app.py

4.ブラウザで表示されるアップロード画面に log.csv をドラッグ＆ドロップ
5.テーブルとグラフが表示されます

---

## CSVフォーマット
CSVは以下の形式で作成してください
```
date,detail
2025-10-18,READMEの記載変更 requirements.txt作成
2025-10-08,UI修正
...
```
date 列はYYYY-MM-DD形式
detail 列はコミットメッセージ
